# 锈星工坊

一个跑在浏览器里的工厂自动化建造游戏。你的登陆舱坠毁在一颗锈色星球上，要从一台钻机开始，搭起自动化生产线、研究科技，最终造出求救信标把信号发出去。

纯前端，没有构建步骤，没有后端。画面用 Three.js 做的斜投影 3D，存档保存在浏览器本地。

## 怎么玩

**Windows**：双击 `启动游戏.bat`，它会在本机起一个静态服务并打开浏览器（需要装有 Python）。

**其他系统**：在项目目录下起任意静态服务，然后打开对应地址。

```bash
python -m http.server 8445
```

打开 <http://localhost:8445/>。

在地址后面加 `?sandbox=1` 是试玩模式：每次都是一张全新地图，不读也不写存档。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 左键 | 放置手中建筑（可拖动连续放置）/ 打开建筑面板 |
| 右键（按住） | 采矿、砍树、拆除建筑 |
| R / Shift+R | 旋转 |
| Q | 放下手中物品 / 吸取鼠标下的建筑 |
| E | 背包与手搓合成 |
| T | 科技树 |
| 1–0 | 快捷栏 |
| Alt | 显示/隐藏进出方向和配方图标 |
| 滚轮 | 缩放 |
| M | 音效开关 |
| F5 | 保存（每分钟也会自动保存） |

游戏里左上角有分步任务提示；机器不工作时头上会有图标，鼠标移上去能看到原因。

## 内容

- **采集与冶炼**：铁、铜、煤、石头四种矿，燃料钻机、电力钻机，石炉、钢炉
- **物流**：传送带、高速传送带、地下传送带、分流器，四种机械臂，三种箱子
- **电力**：抽水泵 → 锅炉 → 蒸汽机，太阳能板，电线杆与电网
- **生产**：两级组装机，手搓队列（自动补做中间零件）
- **研究**：11 项科技，两种数据卡
- **昼夜循环**：夜里太阳能板不发电
- **目标**：研究「深空通讯」，造出求救信标并充满能量

## 目录结构

```
index.html
css/style.css
js/
  data.js       物品、配方、建筑、科技的静态数据
  world.js      地图生成
  entities.js   建筑的创建、放置、库存，电网与管网拓扑，状态诊断
  sim.js        每帧模拟：传送带、机械臂、钻机、熔炉、组装机、发电
  sfx.js        WebAudio 合成音效
  guide.js      物品说明与合成提示
  render.js     渲染入口与 2D 叠加层（电线、图标、进出标注、小地图）
  ui.js         界面：背包、合成、建筑面板、科技树、任务线、剧情
  main.js       玩家、输入、建造、手搓、存档、主循环
  gfx/          3D 渲染：核心、地形着色器、模型、图标烘焙、场景同步
vendor/three.js Three.js r170（MIT 许可）
```
